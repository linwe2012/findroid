## Superseded release

This preview contains the episode navigation changes, but it was published with the wrong Android app identity and signing certificate. It uses package `dev.jdtech.jellyfin.custom` and cannot update the corrected fork app. This was a release identity mistake; it does not indicate a problem with the episode navigation code.

Install the corrected release instead: [Findroid v1.1.0-episode-navigation.6](https://github.com/linwe2012/findroid/releases/tag/v1.1.0-episode-navigation.6).

The corrected release uses package `dev.jdtech.jellyfin.debug`, version code `1000006`, and the same stable fork test signing certificate as the earlier `.5` release. Its displayed app label remains **Findroid Debug**. It is a fork prerelease build, not an official Findroid release.

This old release and its assets remain available for reference. The corrected release above is the one users should install.
